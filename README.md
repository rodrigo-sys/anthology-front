# AnthologyFront

Este proyecto es un cliente web para [a7xnico/anthology](https://github.com/a7xnico/anthology).

Para poder utilizarlo es necesario tener una instancia local activa de anthology:

```bash
git clone 'https://github.com/a7xnico/anthology'
cd anthology
mvnw spring-boot:run
```

> si es necesario, modificar las credenciales y el motor de BBDD en `src/main/resources/application.yaml`.
> antes de ejecutarlo


## Ejecución

```bash
git clone 'https://github.com/rodrigo-sys/anthology-front'
cd anthology-front
npm i
ng serve
```
